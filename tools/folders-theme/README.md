# Animated theme support for openMenu 1.7

This branch is Derek Pascarella's openMenu Virtual Folder Bundle 1.7.0 with one addition: **Folders themes can have an animated
backdrop** (the Dreamcast-BIOS wave scene of the DreamPi web page), glass panels, and rounded popups. Nothing else is changed: no DreamPi
link, no dial-up changes, no Extras menu, no online marks.

## What changed in the code (`openMenu/src/openmenu/src/`)
| File | Change |
|---|---|
| `main.c` | `pvr_init`: `opb_overflow_count` 0 -> 1, so crowded 32x32 tiles do not drop polygons (missing text / holes) |
| `ui/draw_kos.c` | the wave scene (`draw_backdrop`, `draw_backdrop_scene`), glass panels (`draw_draw_panel`), rounded popup frames (`draw_draw_popup_frame`, `draw_set_corner_radius`) |
| `ui/draw_prototypes.h` | prototypes for the above |
| `ui/backdrop_texture.h` | the 64x64 RGB565 cloud texture (generated by `tools/folders-theme/make_backdrop_texture.py`) |
| `ui/theme_manager.c/.h` | new THEME.INI keys (below) |
| `ui/ui_folders.c` | backdrop and panels in `drawOP` / `drawTR`, rounded disc-options popup |
| `ui/ui_menu_credits.c` | popups go through `draw_draw_popup_frame`; the corner radius is set from the theme |

Themes without the new keys look and behave exactly as before.

## New THEME.INI keys (all optional, Folders only)
`menu_corner_radius` (popups, 0 = square), `backdrop` (1 = wave, 2 = low-res wave with fewer triangles), `backdrop_color`,
`panel_0` .. `panel_5` (x,y,w,h), `panel_border_color`, `panel_fill_color`, `panel_alpha`, `panel_radius`, `panel_border_width`.

## The themes (`tools/folders-theme/`)
`python3 build_theme.py` (needs Pillow and numpy) writes three sets, each with `FOLDERS_8` (orange) and `FOLDERS_9` (blue):
`out/` still wave picture (also works on stock openMenu), `out_animated/` full wave, `out_lowres/` 16x16 wave. Install one set into the
card's theme folder. The logo and button icons are cut from the default Folders theme.
