# Test and optimization checklist (NewOpenMenu)

How to use: build `dev`, run it on the Dreamcast, and fill in the `[ ]` boxes and the `=>` lines. Send me the
filled-in file (or just the lines that failed) plus the files listed in section 0. Items marked **(me)** are
things I do without hardware; **(you)** need the console.

- [ ] Console: model/region (PAL/NTSC/JP), BIOS version, video cable (VGA/composite/RGB), TV or monitor, 4:3 or 16:9

- [ ] ICON.DAT / BOX.DAT / META.DAT: which are on the menu disc (name, size)
- [ ] List of games you KNOW are PAL, NTSC-U, NTSC-J (especially ones that share a serial with another region)
- [ ] Photos/screenshots of anything that looks wrong (a phone photo of the TV is fine)
- [ ] What feels slow: boot, scrolling, picture loading, case animation, Files screen? (or: nothing)

## 1. Serial translation audit (the "false positives/negatives" advice)

Where translation happens:
- Card Manager `SerialTranslator.cs`: Table 1 (wrong/duplicate serials, matched on serial + IP.BIN date, one on
  name) is written to the INI and the UI; Table 2 (artwork remap) is used only for BOX.DAT / ICON.DAT keys.
- openMenu `gd_list.c fix_sega_serials()` (same as Table 1, runs on load), `serial_sanitize.c` (art + meta
  remap) and my `serial_region.c` (PAL/NTSC for the disc colour).

Done (me):
- [x] Table 1 in Card Manager and openMenu compared entry by entry: identical (13 date-keyed + the name-keyed
      T0009M/"orth"). Table 2 (12 art remaps) vs openMenu's BOTH entries: identical.
- [x] **Bug found:** the remap tables were never filled in the new app (the init call lived in the old texture
      manager that phase 0 removed), so every art/meta remap was a silent miss. Fixed: the tables fill themselves
      on first use. Host test `serial_sanitize_test.c` fails on the old code (6 failures) and passes now.
- [x] `serial_is_pal` checked against all 215 serials whose region is known from the tables' own sections (PAL
      duplicates, PAL missing meta and their NTSC originals, JAP missing meta, the date-fix targets): one wrong
      (T8103N18, a PAL language variant). Fixed; all 215 now agree.

Still to check:
- [ ] **(me)** Entries that look like typos, to confirm with real discs: `T3601M -> T3602M` and `T3602M -> T3601N`
      (a chain; only one step is applied, so T3601M gets meta of T3602M); targets without the leading T:
      `T45006D50/17701D -> 17701N`, `17707D -> 17707N`; Sega serials pointing at third party serials
      (`MK5102151 -> T40215N`, `MK5109450 -> T44301N`). **(you)**: do those games show the right
      name/players/art? Tell me which games to look at.
- [ ] **(me)** Double application: the Card Manager translates, openMenu translates again. Confirm no entry maps
      onto another entry's key (idempotent). Chains found: only the T3601M/T3602M one.
- [ ] **(you)** Games whose disc colour is wrong (PAL shown red or NTSC shown blue): list name + serial as shown on
      the BACK/button strip. These are the false positives/negatives of `serial_is_pal`.
- [ ] **(you)** Games with no art, wrong art or wrong players/VMU info although the files exist: serial + name.
- [ ] **(you)** Multi-disc sets: all discs grouped, disc numbers right, "1:2" pill correct.
- [ ] **(me)** With your INI: run every serial through Table 1 / Table 2 / meta remap / region and list
      every one that changes, plus every serial `serial_is_pal` is unsure about (no known suffix).
- [ ] Unknown: serials with no region letter (homebrew, Atomiswave `T0006M` style, NAOMI) -> treated as the
      console's region/NTSC. OK for you?

**(me)** to build; **(you)** to read the numbers. Until then, just note the feeling.

Targets (suggestion): 60 fps in every screen, no frame drop when a picture loads, boot to menu under ~5 s.

Optimization work list **(me)**, in this order, each measured before/after on hardware:
- [ ] Debug overlay (fps, tris, VRAM, art cache) behind a button combo
- [ ] Picture loading: DAT reads stall the frame (2 per frame budget today); read ahead / load one per frame,
      keep a small cache for the case + 5 discs, show the plain disc until loaded
- [ ] Case rendering: skip the cases while flying off-screen, drop the translucent edges when far, check sort order
- [ ] Row discs: 32-segment round faces x 5 rows each frame; cache projected geometry when nothing moves
- [ ] Text labels: only re-render a label texture when its text changes; check the title scroll cost
- [ ] Video RAM budget: ROM textures + art cache (20) + disc faces + dynamic icons; free on screen change
- [ ] Per-frame allocations (none wanted); stack use; `malloc` fragmentation after browsing 500 games
- [ ] Boot: what happens before the first frame (INI parse, DAT index, serial table, list sort) and its time
